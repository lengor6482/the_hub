# Assets

Drop real photos, the logo, and any other media here (e.g. `logo.svg`,
`photos/cohort-2024.jpg`), then import them into components the normal
Vite way:

```jsx
import logo from "../assets/logo.svg";
```

The current design ships without photos — the hero and section graphics
are hand-drawn SVG so the site works before real photography is ready.
Swapping in real photos of the hub, cohorts, and mentors is the single
highest-impact change you can make next.
