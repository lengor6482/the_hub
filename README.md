# Aspire! Youth Empowerment and Innovation Hub

Website source, built with React + Vite + Tailwind CSS v4.

## Run it locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

To build a production version:

```bash
npm run build
npm run preview   # preview the production build locally
```

## Folder structure

```
src/
  components/   One file per section (Navbar, Hero, About, Programs, ...)
  pages/        Home.jsx composes the components into the full page
  data/         siteContent.js — all editable text, stats, and lists
  assets/       Drop real photos/logo here (see assets/README.md)
  index.css     Color palette, fonts, and theme tokens (Tailwind v4 @theme)
```

To change any text on the site — headlines, stats, program names,
testimonials, contact info — edit `src/data/siteContent.js`. You
generally shouldn't need to touch the component files for content
changes.
